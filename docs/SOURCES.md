## Evidence limitations and reproducibility

- The original repository was empty apart from .git, and had no tracked application or project instructions on disk. Only research documentation and evidence were added.
- Source data counts enumerate JSON/YAML records at pinned commits. Field coverage means non-empty field presence, not certified correctness. OPT counts include FFF and SLA and source package entries with absent UUIDs.
- OFD barcode validation tested numeric length 8/12/13/14 and the standard alternating-weight check digit only; it did not query GS1 or certify retail assignments.
- Public SpoolmanDB Community compiled JSON was downloaded independently from https://icezaza2543.github.io/SpoolmanDB-Community/filaments.json. Its checksum is recorded in SHA256SUMS. It is not attributed to a proven source build.
- Additional sizing uses compact JSON serialization of source paths/records and gzip; no application database/index was built. It is not a measurement of published SQLite size or phone speed.
- API direct-client 403 results are preserved in research/evidence/downloads.json. Published HTTP validators and binary sizes are unverified.
- Primary docs and source disagree on OFD source format, PAXX alpha representation, U1-RFID diameter, and OPT unreleased diameter keys; the report identifies these conflicts.
- Tests in upstream trees were inventoried but not run. Hardware and production telemetry were not accessed.
