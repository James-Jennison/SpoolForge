# Offline GTIN candidate index

Approved scope: OFD + OpenPrintTag FFF packages + SpoolmanDB Community exact GTIN lookup, provenance per match/field, no automatic field merge. CameraX plus bundled ZXing scans EAN-8, EAN-13, UPC-A, UPC-E, ITF-14, GS1-128 AI (01), and checksum-valid numeric GTIN QR payloads locally. Generic Code 39/Codabar, plain Code 128, arbitrary QR content, and non-GTIN marketplace identifiers are rejected. Frames are not stored or uploaded and the APK has no network permission. Manual GTIN/EAN/UPC-A input remains available.

Inputs are the retained public snapshots; see input-hashes.json. OFD e3888b68f1684f49ec1683022e66b9753d9db3cf, OPT f2fd57dd736cb26a4ff056b3c2a5d1eeaf18e4e5. Community compiled artifact826a544e359d8dc5dd1d4a09f97e7297fd54be1b8589d5f436d64c675cd3f35f is not asserted to match a repository commit. No downloaded source is executed. MIT notices ship with the asset; no artwork is downloaded.

Generate with `heavy-build -- python3 tools/build_gtin_index.py` (Python3, PyYAML). Independently verify with `heavy-build -- python3 tools/verify_gtin_index.py`. The asset is bundled explicitly, not fetched/rebuilt through the mobile client. All input checksums, exclusions, schema format and output hashes are inspectable. SQLite is opened read-only; a verified temporary file replaces an absent/corrupt sidecar. Existing OFD and user data are preserved; UserDatabase2->3 adds only barcode_evidence.

OFD package IDs are unchanged. Community candidate IDs combine its unique upstream ID with package scope, so row reordering does not change identity; the build fails if Community IDs cease to be unique. OpenPrintTag candidate IDs include the pinned record location because its upstream IDs collide, so OPT identity is snapshot-record identity and future refreshes need an explicit crosswalk. Source record IDs and paths remain separate; no live refresh is implemented.

Barcodes validate ASCII digits/length/check digit, retain raw representation and normalize to a14-character comparison key. Invalid claims remain in rejected-identifiers.json. OPT FFF only; µm converted to mm; non-opaque RGBA is flagged and left without a guessed RGB. Community associations carry a package-confirmation warning and compiled-origin limitation; explicit refill mismatches are excluded. Single recommended temperatures are not fabricated into ranges. Source records/values, conflicts, license, revision/artifact hash and path accompany every match. Repeated same-key/source/ID conflicting values are never silently overwritten.

Initial bundle:8219 keys,14706 source candidates,62717952 uncompressed bytes, about4MB gzip. These are candidate associations, not verified unique retail products. Lookup uses the primary B-tree key, not FTS. Selection does not write a tag. Existing NFC validation and overwrite consent still apply. Barcode evidence persists in recents and local edits; edited field sources remain separate from immutable original-match evidence.

Acceptance evidence: the bundle oracle passes 44,991 input hashes and every candidate record; sample multi-package barcode 7340002119380 retains all four Community weight/diameter combinations. Host tests cover normalization, camera-frame rotation and decode, sidecar corruption recovery, provenance snapshots, and user migration/storage. On the 2023 Razr, installation preserved user data, the camera permission and live preview worked, and instrumentation repaired a deliberately corrupted sidecar while returning the same candidates. A live package scan decoded linear GTIN 00080238000089; a Polymaker package with an Amazon FNSKU plus a GTIN QR decoded the QR as 06938936717461 while rejecting the FNSKU. Both correctly returned zero candidates in the retained source snapshots.

The product is **Filamajig NFC**, with the tagline *Tap it. Tag it. Print it.* and app-store name **Filamajig NFC: Spool Tagger**. Its Android application ID and Kotlin namespace are `net.jamesjennison.filamajignfc`. The prior local prototype data was migrated on the 2023 Razr with database and preference-file hash verification; internal database and bundle format identifiers remain stable.
